# 长清阁麻将 - 牌背颜色方案调研报告

## 项目背景

- **当前牌背**: `pomax_hq/Back.png` (36×50px 小图)
- **牌桌颜色**: `linear-gradient(135deg, #1f8a52, #46c574)` — 深绿色台布
- **需求**: 奇数局/偶数局使用不同牌背颜色，增加视觉区分感

---

## 牌背颜色方案推荐

### 方案一：经典红木色（奇数局）⭐ 推荐

**风格**: 传统麻将经典配色，沉稳大气

| 颜色角色 | 色值 | 说明 |
|---------|------|------|
| 主色 | `#8B2500` (深红木) | 牌背主体色 |
| 辅色 | `#CD853F` (秘鲁色/浅红木) | 图案高亮、边框 |
| 阴影色 | `#4A1500` (暗红木) | 立体感、边缘阴影 |
| 点缀色 | `#DAA520` (金黄) | 装饰线条 |

**CSS 渐变方案**:
```css
/* 经典红木色牌背 */
background:
  linear-gradient(180deg,
    rgba(255,255,255,0.12) 0%,
    rgba(255,255,255,0.03) 30%,
    transparent 55%,
    rgba(0,0,0,0.35) 100%),
  linear-gradient(155deg,
    #B8461E 0%,
    #8B2500 35%,
    #5C1A00 65%,
    #3A0F00 100%);
border: 0.5px solid rgba(205, 133, 63, 0.4);
box-shadow:
  inset 0 1px 2px rgba(255,255,255,0.15),
  inset 0 -1px 3px rgba(0,0,0,0.4),
  0 2px 4px rgba(0,0,0,0.3);
```

**视觉特点**: 深红木色与深绿台布形成暖-冷对比，经典麻将感强

---

### 方案二：象牙白/米色（偶数局）⭐ 推荐

**风格**: 清新明亮，与深绿台布形成高对比

| 颜色角色 | 色值 | 说明 |
|---------|------|------|
| 主色 | `#F5F5DC` (米色/象牙白) | 牌背主体 |
| 辅色 | `#E8DCC8` (淡黄褐) | 立体阴影 |
| 阴影色 | `#C4B89A` (深米色) | 边缘深度 |
| 点缀色 | `#8B7355` (深褐) | 图案线 |

**CSS 渐变方案**:
```css
/* 象牙白牌背 */
background:
  linear-gradient(180deg,
    rgba(255,255,255,0.3) 0%,
    rgba(255,255,255,0.08) 30%,
    transparent 55%,
    rgba(0,0,0,0.2) 100%),
  linear-gradient(155deg,
    #FFFFF0 0%,
    #F5F5DC 30%,
    #E8DCC8 60%,
    #D4C4A8 100%);
border: 0.5px solid rgba(139, 115, 85, 0.35);
box-shadow:
  inset 0 1px 2px rgba(255,255,255,0.5),
  inset 0 -1px 3px rgba(0,0,0,0.15),
  1px 2px 0 #8a7a5a,
  2px 4px 0 #6a5a3a;
```

**视觉特点**: 浅色牌背在深绿台布上非常醒目，层次分明

---

### 方案三：深蓝/藏蓝色（备选）

**风格**: 高端商务，深沉典雅

| 颜色角色 | 色值 | 说明 |
|---------|------|------|
| 主色 | `#1A237E` (深藏蓝) | 牌背主体 |
| 辅色 | `#3949AB` (靛蓝) | 高光区域 |
| 阴影色 | `#0D1642` (暗蓝黑) | 边缘阴影 |
| 点缀色 | `#C5CAE9` (浅蓝灰) | 装饰线 |

**CSS 渐变方案**:
```css
/* 深蓝藏青牌背 */
background:
  linear-gradient(180deg,
    rgba(255,255,255,0.12) 0%,
    rgba(255,255,255,0.03) 30%,
    transparent 55%,
    rgba(0,0,0,0.4) 100%),
  linear-gradient(155deg,
    #3949AB 0%,
    #1A237E 35%,
    #0D1642 65%,
    #070B24 100%);
border: 0.5px solid rgba(197, 202, 233, 0.25);
box-shadow:
  inset 0 1px 2px rgba(255,255,255,0.12),
  inset 0 -1px 3px rgba(0,0,0,0.45);
```

**视觉特点**: 深蓝与深绿属于相近色系（都是冷色调），和谐统一，有高级感

## 三种方案对比

| 特性 | 方案一 红木色 | 方案二 象牙白 | 方案三 深蓝色 |
|-----|-------------|-------------|-------------|
| 与深绿台布对比 | ⭐⭐⭐ 强对比 | ⭐⭐⭐⭐⭐ 最强对比 | ⭐⭐ 中等对比 |
| 传统麻将感 | ⭐⭐⭐⭐⭐ 最强 | ⭐⭐⭐ 中等 | ⭐⭐ 低 |
| 视觉区分度(奇/偶) | ⭐⭐⭐⭐⭐ 好 | ⭐⭐⭐⭐⭐ 极好 | ⭐⭐⭐ 一般 |
| 实施难度 | 简单(CSS) | 简单(CSS) | 简单(CSS) |

---

## 推荐方案

**推荐使用 方案一 + 方案二 的组合**：

- **奇数局**: 经典红木色 `#8B2500`
- **偶数局**: 象牙白 `#F5F5DC`

**理由**:
1. 两种方案都是纯CSS实现，无需替换图片资源
2. 暖色（红木）vs 冷色（象牙白）形成强烈视觉区分
3. 与深绿台布都能形成良好对比
4. 红木色延续传统麻将风格，象牙白则现代清新

## 实施建议

可以在 `MahjongTile.vue` 中添加一个 `roundType` (odd/even) prop，根据奇偶局动态切换牌背样式：

```vue
<template v-else>
  <div 
    class="tile-img" 
    :class="roundType === 'odd' ? 'tile-back-redwood' : 'tile-back-ivory'"
    :style="roundType === 'odd' ? redwoodStyle : ivoryStyle"
  ></div>
</template>
```

或者更简单：在 `gameroom/[roomId].vue` 全局注入 CSS 变量，牌背组件直接读取。
