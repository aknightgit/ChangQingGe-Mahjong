## 二、回合流程

```
摸牌 → 可杠/可胡 → 打牌 → 他人抢牌窗口 → 下家摸牌
```

### 2.1 动作优先级
**胡 > 杠 > 碰 > 吃**

| 动作 | 触发 | 说明 |
|------|------|------|
| 摸牌 | 轮到自己 | 必须先摸后打 |
| 打牌 | 摸牌后 | 必须打出一张 |
| 吃 | 上家打牌 | 只能吃上家 |
| 碰 | 任意家打牌 | 优先级高于吃 |
| 杠 | 任意家第4张/手里4张 | 明杠/暗杠/补杠 |
| 自摸 | 自己摸牌成胡 | 优先级最高 |
| 捉冲 | 他人打牌成胡 | 优先级最高 |

### 2.2 冻结机制（抢牌窗口）
上家出牌后，**并行**推进两个流程：
- **Pending窗口**：其他玩家看到碰/杠/胡按钮（时长由决策犹豫期参数确定）
- **冻结计时器**：下家等待，时间到自动摸牌

谁先完成谁赢：有人抢牌→立即执行；无人抢→下家自动摸牌。

### 2.3 超时规定
- 摸牌后 **60秒** 未出牌 → 自动打出摸到的牌
- 连续 **2次** 超时 → AI 接管该玩家
- 点击「我回来了」恢复控制
- AI接管过，本局结算时赢只收一半。下局恢复正常

## 三、百搭系统

- 每局**随机指定一张**为百搭（不从牌墙移除）
- 百搭可替代任意牌参与胡牌
- 百搭打出后**不可被吃/碰/杠**
- 百搭打出触发**一圈冷冻**（4人各出一张后解冻），期间不可吃/碰/捉冲

### 花牌百搭
- 百搭为春夏秋冬 → 四张花牌全部为百搭
- 百搭为梅兰竹菊 → 四张花牌全部为百搭
- 百搭花牌摸到后**进入手牌**（不放门口，不补花）

## 四、胡牌牌型

### 4.1 牌型列表

| 牌型 | 点数 | 说明 |
|------|------|------|
| 风碰 | 40 | 风一色+碰碰胡 |
| 风一色 | 20 | 全风牌/箭牌 |
| 清碰 | 20 | 清一色+碰碰胡 |
| 大吊 | 10 | 手牌仅剩1张单听 |
| 杠开 | 10 | 杠后补牌自摸 |
| 八花自摸 | 10 | 独家摸齐8朵花+自摸 |
| 无花自摸 | 10 | 碰碰胡/混一色+自摸+门口无花+无风向刻杠 |
| 清一色 | 10 | 仅一门花色 |
| 混碰 | 10 | 混一色+碰碰胡 |
| 四百搭 | 10 | 手牌有4张百搭 |
| 混一色 | 公式 | 一门花色+字牌 |
| 碰碰胡 | 公式 | 全刻子+对子 |

### 4.2 公式计算
```
基础点数 = 2 + 花牌数 + 组合牌点数
组合牌点数: 风刻=1, 箭刻=2, 风杠=2, 箭杠=3, 其他杠=1, 暗杠+1
上限: 10点
```

### 4.3 额外翻倍
| 条件 | 倍数 |
|------|------|
| 无百搭 | ×2 |
| 门清（无吃/碰/明杠，暗杠不破） | ×2 |

### 4.4 捉冲/抢杠限制
- 碰碰胡/混一色：门口必须有**有效番数**才可捉冲/抢杠
- **有效番数**：花牌、风箭刻（风牌/箭牌刻子或杠）、任意杠牌
- 例外：大吊不受此限，可随时捉冲
- 例外：固定点数≥10的牌型不受此限

## 五、杠牌与抢杠

| 类型 | 条件 | 可抢杠 |
|------|------|--------|
| 暗杠 | 手里4张 | ❌ 不可抢 |
| 明杠 | 他人打出第4张 | ❌ 不可抢 |
| 补杠 | 门口刻子+自摸第4张 | ✅ 可抢杠 |

- 抢杠结算：牌型点数 × 3，仅杠家赔付

## 六、互包规则（包三/包四）

| 关系 | 条件 | 赔付 |
|------|------|------|
| 包三 | 吃/碰/杠另一方 3口 | ×3 |
| 包四 | 吃/碰/杠另一方 4口 | ×5 |

### 结算
| 场景 | 规则 |
|------|------|
| 互包双方互相放冲 | 统一 ×2 |
| 第三方放冲 | 放冲者×1，互包输家向胜者×1 |
| 自摸（三口） | 互包输家×3，其他玩家×1 |
| 自摸（四口） | 互包输家×5，其他玩家不赔付 |

## 七、点数结算

```
最终点数 = 牌型点数 × 额外翻倍 × 全局倍数
全局倍数 = min(8, 骰子倍数 × 流局倍数 × 继承倍数)
```

| 因子 | 规则 |
|------|------|
| 骰子倍数 | 1+1或4+4=×4，其他对子=×2，其他=×1 |
| 流局倍数 | 上局流局/造反=×2，否则=×1 |
| 继承倍数 | 来自上局全局倍数链路 |
| 封顶 | 全局倍数上限 8，超出部分后台继承到下局 |

## 八、特色玩法

### 8.1 造反（五毒散）
**触发条件**（首轮摸满手牌时）：
- 筒/万/条三门都有
- 有风牌 + 有箭牌
- 无花牌、无百搭、无对子/刻子

**效果**：本局直接结束 → 下局全局倍数 ×2 → 造反者成庄家

### 8.2 梁山聚义
- 4人全真人局，前3回合可发起
- 累积赢分超过 QJ线（默认4000）的玩家自动同意
- 全员通过 → 本局结束，下局翻倍

### 8.3 谢谢带头大哥
- 某玩家打出某张牌，随后同回合内其他3玩家全部打出同样牌
- 该玩家赔付其余三家每家 10 分（胡牌结算时一起扣除，带备注）

### 8.4 换座
- 有效输分达到 QJ线（默认4000）可发起
- 输4000=1次机会，输8000=2次，输12000=3次（最多10次）
- 下一局开始前生效

## 九、花牌规则

- 摸到花牌 → 放入副露区 → 从牌墙**尾部**补牌
- 补到花牌 → 继续补，直到非花牌
- 花牌不参与胡牌牌型判断

---

## 十、流局

- 牌墙摸完无人胡牌 → 流局
- 流局 → 下局全局倍数 ×2
