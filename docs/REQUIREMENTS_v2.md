### 2.3 弃牌区详细规格

**数量**：每行6张，自动换行（6×n 网格）

**分数标注**（每张弃牌右侧）：

**朝向旋转**：
- 上家弃牌：旋转180°

- 左家：露牌在手牌上方
- 右家：露牌在手牌下方

**分数标注**：
- 每个露牌组合（碰/杠）有分数标注（x2, x4 等）
- 显示该组合在本局的得分倍率

**来源标记**：
- 碰/杠/吃有来源玩家标注（颜色圆点或箭头）

## 四、交互功能需求

### 4.1 人类玩家操作

**出牌方式（双保险）：**
1. **双击出牌**：点击选中手牌 → 再次点击该牌 → 出牌
2. **拖拽出牌**：拖拽手牌 → 松手在弃牌区 → 出牌

**操作按钮**（根据规则自动显示）：
- 摸牌（自己的回合可摸）
- 吃（仅下家可吃上家打出的牌）
- 碰
- 杠
- 胡
- 过（pass）

**碰/杠/胡响应**：有人打出可碰/杠/胡的牌时，弹出操作选项

### 4.2 AI Bot 自动操作

**识别方式**：玩家名字以"电脑"开头

**自动行为**：
- 轮到 AI 回合 → 自动摸牌（延迟800ms，让客户端看到动画）
- 自动评估手牌 → 根据 `best-policy.json` 策略选最佳出牌
- 自动出牌
- 有人打出可碰/杠/胡的牌 → AI 自动决定是否响应

**策略参数**（来自训练好的 best-policy.json）：
- selfWinChance: 0.99
- discardHuChance: 0.73（避免打出危险牌）
- pengChance: 0.66
- kongChance: 0.59
- chowChance: 0.64
- wildKeepPenalty: 1249（保留百搭）

### 4.3 游戏流程

1. 创建房间 → 4人加入（1人 + 3电脑）
2. 点"掷骰子开局" → 骰子动画 → 确定庄家 → 发牌
3. 庄家摸14张，其他13张
4. 轮流摸牌 → 出牌（人类点击/拖拽，AI自动）
5. 有人打出可响应牌 → 碰/杠/胡 → 结算 → 继续
6. 牌墙打完 → 流局 → 结算
