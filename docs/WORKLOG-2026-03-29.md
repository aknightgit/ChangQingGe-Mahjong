## 二、游戏流程重构

### 2.1 开局流程（掷骰子→发牌）
1. 创建房间弹窗：骰子次数/AI玩家选择/冻结秒数
2. 进入房间→自动弹出骰子overlay
3. 庄家点击骰子掷骰(3D弹跳动画，1.8s)
4. 结果阶段：点击骰子可重掷，"发牌"按钮常驻
5. 点击发牌→调用startGame API→发牌→游戏开始

### 2.2 回合流程（简化版）
1. 上家出牌→moveToNextPlayer
2. 回合开始自动补花（所有玩家）
3. 冻结期（默认1秒）
4. Bot：延迟后自动摸牌+出牌(0.5~2s随机)
5. 人类：显示"摸"按钮，手动点击摸牌→出牌

### 2.3 关键规则变更
- **去掉碰/杠/胡响应窗口**：不再checkPendingActions，直接进入下家
- **去掉"过"检查**：游戏正常流转，不做等待
- **冻结机制替代**：上家打牌后下家等待N秒
- **人类不自动摸牌**：需手动点击"摸"
- **庄家自动补花**：开局所有玩家花牌自动替换
