## 1. 需求说明

### 1.1 这是什么 App

长清阁麻将 — 一个可联网的 4 人麻将 App，支持人类 + AI Bot 对战。

### 1.2 核心功能清单

| 编号 | 功能 | 描述 |
|------|------|------|
| F-01 | 创建/加入房间 | 创建房间 → 发给朋友 → 4人加入 |
| F-02 | 人机大战 | 1人 + 3个AI Bot 自动对战 |
| F-03 | 掷骰子开局 | 骰子动画 → 确定庄家 → 发牌13/14张 |
| F-04 | 基本牌局流转 | 摸牌 → 出牌，轮流进行 |
| F-05 | 吃/碰/杠/胡 | 根据规则自动判定可用操作 |
| F-06 | 花牌 | 自动补花 |
| F-07 | 百搭牌 | 随机选牌，冷冻机制 |
| F-08 | 造反 | 五毒散检测 + 流程 |
| F-09 | 互包 | 包三/包四，结算倍率 |
| F-10 | 流局倍数继承 | 流局 ×2 封顶 8，正常结局 ×1 |
| F-11 | 杠上开花 | 杠牌后自摸检测 |
| F-12 | 大吊胡 | 特殊胡牌 |
| F-13 | 抢杠 | 有人加杠时抢胡 |
| F-14 | 一炮多响 | 多人同时胡 |
| F-15 | 结算倍数 | 全局倍数 × 局倍数 |

## 2. 需求拆解

### 2.1 UI 完整拆解（从参考图推断）

#### 2.1.1 桌面结构
- 2.1.1.1 **四人桌俯视**：上/下/左/右各一人
- 2.1.1.2 **桌面背景**：绿色或蓝色渐变（两套主题色）
- 2.1.1.3 **中央区域**：弃牌区（6×n 网格，牌面朝上）

#### 2.1.2 每个玩家的区域
- 2.1.2.1 **手牌区**（在对应方位的桌面边缘）
  - 本家（下方）：手牌正面朝上，能看到自己的牌
  - 其他三家：手牌背面或侧面朝玩家

#### 2.1.7 牌面方向（各位置玩家视角）

> 原则：每个玩家看到的牌面正方向 = 该玩家面对牌桌时"正面朝自己"的方向。

- 2.1.7.1 **本家（下/south）**：牌面正方向朝下（牌头朝上）→ `rotate(0deg)`
- 2.1.7.2 **上家（top/north）**：牌面正方向朝上（倒过来）→ `rotate(180deg)`
- 2.1.7.3 **左家（left/west）**：牌面正方向朝右 → `rotate(90deg)`
- 2.1.7.4 **右家（right/east）**：牌面正方向朝左 → `rotate(270deg)`

**适用范围（统一方向）：**
- 2.1.7.5 弃牌区：每张弃牌按 2.1.7.1~2.1.7.4 旋转
- 2.1.7.6 手牌区（其他玩家）：牌背朝牌桌中心方向
- 2.1.7.7 露牌区：牌面朝上，头部朝向同该玩家方向
- 2.1.7.8 牌墙：牌背朝上

**CSS 实现（通过外层 `.seat` 旋转覆盖）：**
```css
.seat-top    { transform: translateX(-50%) rotate(180deg); }
.seat-bottom { transform: translateX(-50%) rotate(0deg); }
.seat-left   { /* 内部牌 rotate(90deg) */ }
.seat-right  { /* 内部牌 rotate(270deg) */ }
```

### 2.2 游戏逻辑完整拆解

#### 2.2.1 开局流程
- 2.2.1.1 房主创建房间 → 其他玩家加入
- 2.2.1.2 **人机大战模式**：房主点击"人机大战"按钮 → 3个AI Bot自动加入 → 自动掷骰子动画+随机确定百搭牌→玩家做庄家先出牌
- 2.2.1.3 **联网模式**：4个人类玩家加入 → 房主点"开始"
- 2.2.1.4 掷骰子动画（骰子1+骰子2）→ 定庄家
- 2.2.1.5 确定本局百搭牌（随机）
- 2.2.1.6 验证剩余牌墙数 ≥ 所有人需要摸的张数
- 2.2.1.7 发牌：庄家14张，其余13张
- 2.2.1.8 补花（轮到玩家回合如有花牌自动从墙补入，需要动画）
- 2.2.1.9 进入 PLAYING 阶段

#### 2.2.2 回合流转
- 2.2.2.1 **当前玩家**（currentPlayerIndex）进入回合
- 2.2.2.2 **人类玩家**：显示"摸牌"按钮 → 点击摸牌 → 手牌更新
- 2.2.2.3 **AI Bot**：自动摸牌（延迟800ms让客户端看到动画）
- 2.2.2.4 摸牌后检查：
  - 能自摸胡？→ 显示胡按钮（人类）/ 自动胡（AI）
  - 能杠？→ 显示杠按钮（人类）/ 自动杠（AI）
- 2.2.2.5 出牌：
  - 人类：双击或拖拽出牌，拖拽可悔，应设置有效弃牌区
  - AI：策略选出牌 → 延迟300-700ms出牌
- 2.2.2.6 出牌后检查所有其他玩家：
  - 能碰？→ 显示碰按钮（人类）/ 自动碰（AI）
  - 能杠？→ 显示杠按钮（人类）/ 自动杠（AI）
  - 能胡？→ 显示胡按钮（人类）/ 自动胡（AI）
  - 能吃？→ 显示吃按钮（仅下家，人类）/ 自动吃（AI）
- 2.2.2.7 犹豫响应期内（参数化，建房时可选，有默认1秒）无响应 → 进入下一玩家回合
- 2.2.2.8 犹豫响应期内有人响应 → 短暂暂停（300-700ms）→ 执行操作 → 继续

#### 2.2.3 操作规则
- 2.2.3.1 **碰**：任意一家打出同牌2张 → 用手中2张组成碰
- 2.2.3.2 **杠**：碰后加杠 / 手持4张同牌暗杠 / 手持3张+1张明杠
- 2.2.3.3 **吃**：仅下家，上家打出的牌能组成顺子
- 2.2.3.4 **胡**：满足牌型要求（允许垃圾胡）
- 2.2.3.5 **过**：放弃响应，进入正常流转
- 2.2.3.6 **响应优先级**：胡 > 杠 > 碰 > 吃

#### 2.2.4 特殊规则
- 2.2.4.1 **百搭牌**：开局随机选一张，可充当任何牌
- 2.2.4.2 **冷冻机制**：打出百搭后一圈内不能碰杠捉冲
- 2.2.4.3 **造反**：首轮五毒散检测（有条有筒有万有风有箭无花无百搭无对子）
- 2.2.4.4 **流局继承倍数**：牌墙打完无人胡 → 全局倍数 ×2 封顶 8
- 2.2.4.5 **杠上开花**：杠牌后自摸 → 特殊加分
- 2.2.4.6 **互包**：包三/包四，结算乘数特殊
- 2.2.4.7 **大吊胡**：只剩2张牌时胡（吃碰杠后单听）
- 2.2.4.8 **一炮多响**：多人同时胡 → 全部给分
- 2.2.4.9 **抢杠**：有人加杠时，其他人可用该牌胡，三倍结算

#### 2.2.5 结算
- 2.2.5.1 **局倍数**：掷骰子确定（骰子1+骰子2 × 掷骰总数），×2 封顶 8
- 2.2.5.2 **全局倍数**：流局 ×2 封顶 8，正常结局 ×1
- 2.2.5.3 **最终结算**：全局倍数 × 局倍数 × 牌型点数
- 2.2.5.4 **互包乘数**：包三×3，包四×5
- 2.2.5.5 **放冲乘数**：放冲 ×2
- 2.2.5.6 **自摸乘数**：自摸 ×2（除自摸者外均付）

### 2.3 AI Bot 策略完整拆解

#### 2.3.1 策略来源
- 2.3.1.1 训练文件：`training/best-policy.json`（第10轮冠军，95.9%胡牌率）
- 2.3.1.2 策略参数包括：自摸概率、碰概率、杠概率、吃概率、危险牌避免等

#### 2.3.2 评分函数
- 2.3.2.1 对每张手牌计算"出牌分值"
- 2.3.2.2 分值 = 胡牌概率提升 × 自摸概率 - 危险牌惩罚
- 2.3.2.3 选最高分值的牌出牌

#### 2.3.3 碰/杠/胡决策
- 2.3.3.1 碰：手中有2张同牌 + 随机概率 < pengChance(0.66)
- 2.3.3.2 杠：手中有3张同牌 + 随机概率 < kongChance(0.59)
- 2.3.3.3 胡：能胡 + 随机概率 < selfWinChance(0.99) → 基本一定胡
- 2.3.3.4 吃：手中缺2牌中1牌 + 随机概率 < chowChance(0.64)
