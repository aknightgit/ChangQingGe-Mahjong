# 🀄 长清阁麻将 - 规则明细

> 长清阁麻将玩法，完整规则定义

---

## 一、基础配置

| 项目 | 规则 |
|------|------|
| **牌数** | 144张（含8张花牌） |
| **玩家** | 4人 |
| **庄家** | 骰子决定，可掷2次取最优 |
| **起牌** | 庄家14张，闲家13张 |
| **战斗模式** | 长清阁（血战到底） |

---

## 二、牌具

### 2.1 牌组构成

| 类型 | 牌种 | 每种张数 | 小计 |
|------|------|----------|------|
| **万子** | 一万~九万 | 4张 | 36张 |
| **筒子** | 一筒~九筒 | 4张 | 36张 |
| **条子** | 一条~九条 | 4张 | 36张 |
| **风牌** | 东/南/西/北 | 4张 | 16张 |
| **箭牌** | 红中/发财/白板 | 4张 | 12张 |
| **花牌** | 春/夏/秋/冬/梅/兰/竹/菊 | 1张 | 8张 |

**总计: 144张**

### 2.2 百搭牌

- 每局从144张牌中**随机指定一张**作为百搭（不从牌墙移除）
- 百搭可替代任意牌参与胡牌判定
- 百搭打出后**不可被吃/碰/杠**

#### 花牌百搭

- 花牌可以作为百搭牌
- 若百搭牌为**春夏秋冬**中任意一张，则四张花牌**全部为百搭**
- 若百搭牌为**梅兰竹菊**中任意一张，则四张花牌**全部为百搭**
- 百搭花牌摸到后**进入手牌**（不放门口，不补花）
- 普通花牌摸到后仍放门口，等回合补花

#### 百搭牌打出冷冻

- 百搭牌被打出时，触发**一圈冷冻**
- 冷冻期间：所有玩家**不能吃/碰/捉冲**
- 冷冻持续**一圈**（四个玩家各出一张牌后解冻）

#### 百搭与风一色/风碰的特殊结算

- 若百搭牌为**风牌或箭牌**，且胡牌牌型为**风一色**，则可算作**无百搭**（享受×2翻倍）
- 若百搭牌为**风牌或箭牌**，且胡牌牌型为**风碰**，则需验证：去掉百搭功能后（百搭当作普通牌），牌面仍满足**全是对子+刻子**，才可算作**无百搭**（享受×2翻倍）
- 逻辑：风一色/风碰由风牌+箭牌组成，百搭归位后仍属于同一牌组

## 三、通用动作

| 动作 | 触发条件 | 优先级 |
|------|----------|--------|
| **摸牌** | 轮到自己回合 | 1 |
| **打牌** | 摸牌后必须打一张 | 2 |
| **吃牌** | 上家打牌可吃 | 3 |
| **碰牌** | 任意家打牌可碰 | 4 |
| **明杠** | 任意家打出第4张可杠 | 5 |
| **暗杠** | 手里有4张相同牌 | 5 |
| **补杠** | 碰牌后摸到第4张 | 5 |
| **胡牌(自摸)** | 自己摸牌成胡 | 6 |
| **胡牌(捉冲)** | 他人打牌成胡 | 6 |
| **胡牌(抢杠)** | 抢他人补杠的牌胡 | 6 |

**优先级**: 胡 > 杠 > 碰 > 吃

---

## 四、回合规则

1. **先摸后打**: 轮到自己必须先摸牌，再打出一张
2. **一回合一张**: 每次摸牌后只能打出一张
3. **吃牌限制**: 只能吃**上家**打出的牌
4. **一炮多响**: 允许多家同时胡同一张牌，从首个胡家**右手**继续

---

## 五、花牌规则

- 摸到花牌 → 花牌放入副露区 → 从牌墙**尾部**补牌
- 补到花牌 → 继续补，直到补到非花牌
- 花牌不参与胡牌牌型判断
- **八花自摸**: 手牌+副露共8朵花且自摸 = **固定10点**

---

## 六、杠牌规则

| 类型 | 条件 | 特殊规则 |
|------|------|---------|
| **暗杠** | 手里4张相同 | 不露牌面，不破门清 |
| **明杠(补杠)** | 他人打出第4张 | - |
| **自摸补杠** | 自己摸到第4张 | 门口刻子补杠可被**抢杠** |
| **杠花** | 花牌自动杠补 | 从牌墙尾补牌 |

### 抢杠规则

- **仅**在"门口刻子 + 自摸第4张"补杠时可被抢杠
- 手里三张自摸补杠视为暗杠，**不可抢杠**
- 若牌型为碰碰胡/混一色，门口**必须有花牌**才可抢杠
- 例外：若属于**大吊**（如"碰碰胡大吊"/"混一色大吊"），则不受"无花不能捉冲"限制，可随时抢杠/捉冲
- 抢杠结算: 牌型点数 × 3，仅杠家赔付
- 抢杠后赢家右手玩家继续摸牌

## 七、胡牌牌型

### 7.1 牌型列表

| 牌型 | 手牌要求 | 门口牌要求 | 允许花牌/百搭 |
|------|---------|-----------|---------------|
| **碰碰胡** | 全是刻子+对子 | 全是刻子+杠 | ✅ |
| **清一色** | 仅一门花色 | 仅一门花色 | ✅ |
| **混一色** | 一门花色+字牌 | 一门花色+字牌 | ✅ |
| **混碰** | 混一色+碰碰胡 | 一门花色+字牌，且全刻子/杠 | ✅（门口无花也可捉冲） |
| **清碰** | 清一色+碰碰胡 | 清一色+碰碰胡 | ✅ |
| **风一色** | 全是风牌或箭牌 | 全是风牌或箭牌 | ✅ |
| **风碰** | 风一色+碰碰胡 | 全是风牌/箭牌刻子/杠 | ✅ |
| **七对** | 7个对子 | - | ✅ |
| **八花自摸** | 手牌+副露共8花 | - | ✅ |
| **四百搭** | 手牌有4张百搭 | - | ✅ |
| **大吊** | 手牌仅剩1张，单听1张胡牌 | 至少有门口副露，且胡牌后手牌仅2张 | ✅ |

### 7.2 牌型优先级（高→低）

> 说明：大吊不新增独立番种链路，按固定10点处理；且优先级低于风碰/风一色。

1. 风碰(40点)
2. 风一色(20点)
3. 大吊(10点，固定；仅低于风碰/风一色)
4. 清碰(20点)
5. 混碰(10点，固定)
6. 八花自摸(10点)
7. 清一色(10点)
8. 杠开(10点)
9. 无花自摸(10点，仅碰碰胡/混一色)
10. 四百搭(10点)
11. 混一色(公式计算)
12. 碰碰胡(公式计算)

## 八、门清判定

**门清条件**:
- 没有吃过牌
- 没有碰过牌
- 门口无吃/碰/明杠的牌组
- ✅ 允许暗杠和杠花

---

## 九、无花自摸

### 触发条件
- 牌型为**碰碰胡**或**混一色**
- **自摸胡牌**（非放冲）
- 门口**没有花牌**
- 手牌**没有风向刻子或风向杠**

### 结算
- 固定点数 **10点**

---

## 十、造反规则

### 触发条件（五毒散）

开局后首轮摸满手牌，轮到自己回合时手牌同时满足：
- 筒子、万子、条子**三门都有**（每门≥1张）
- 有风牌（东南西北任意）
- 有箭牌（中发白任意）
- **无花牌**
- **无百搭**
- **无对子或刻子**（全是搭子/散牌）

### 效果
- 显示"我要造反/不造反"选项
- 选择造反 → **本局直接结束**
- **下局倍数 ×2**
- 造反者成为庄家

---

## 十一、互包规则（包三/包四）

### 触发条件

| 关系 | 条件 | 赔付倍数 |
|------|------|---------|
| **包三** | 吃/碰/杠另一方**3口** | ×3 |
| **包四** | 吃/碰/杠另一方**4口** | ×5 |

### 约束
- 吃牌只能吃上家
- 碰牌和杠牌可碰任意家

### 结算规则

#### 互包双方互相放冲
- 统一按 **2倍** 结算

#### 第三方放冲
- 放冲者按 **1倍** 赔付
- 互包输家向胜者赔付 **1倍**

#### 自摸
- **三口互包**: 互包输家赔 **3倍**，其他玩家 **1倍**
- **四口互包**: 互包输家赔 **5倍**，其他玩家 **不赔付**

## 十二、点数结算

### 固定点数牌型

| 牌型 | 点数 |
|------|------|
| 清一色 | 10点 |
| 风一色 | 20点 |
| 风碰 | 40点 |
| 清碰 | 20点 |
| 混碰 | 10点 |
| 无花自摸 | 10点 |
| 杠开 | 10点 |
| 八花自摸 | 10点 |
| 四百搭 | 10点 |
| 大吊 | 10点 |

### 公式计算牌型（碰碰胡/混一色，不含混碰）

```
基础点数 = 2 + 花牌数 + 组合牌点数
```

**组合牌点数**:
- 风牌刻子 = 1点
- 箭牌刻子 = 2点
- 风牌杠 = 2点
- 箭牌杠 = 3点
- 其他牌杠 = 1点
- 暗杠 = 上述 + 1点

> 公式点数**上限10点**

### 额外翻倍

| 条件 | 倍数 |
|------|------|
| 无百搭 | ×2 |
| 门清 | ×2 |

### 最终公式

```
最终点数 = 牌型点数 × 额外翻倍 × 全局倍数
```

统一命名：

```
全局倍数 = min(
  8,
  骰子倍数（清晰明了） ×
  流局倍数（造反也算） ×
  继承倍数（上把的全局倍数）
)
```

- **骰子倍数（清晰明了）**：
  - 1+1 = ×4
  - 4+4 = ×4
  - 其他对子 = ×2
  - 其他 = ×1
- **流局倍数（造反也算）**：
  - 上一局若“流局”或“造反”则 = ×2
  - 否则 = ×1
- **继承倍数（上把的全局倍数）**：
  - 来自上一局全局倍数链路，允许后台继续叠加
  - 但本局结算显示和生效仍受 `min(8, ...)` 封顶

---

## 十三、流局与翻倍（继承规则）

- 流局 → 下局“全局继承倍数” **×2**
- 造反 → 下局“全局继承倍数” **×2**
- 若某局已达结算封顶×8，后续再发生流局/造反时：
  - 下局仍按封顶 **×8** 结算
  - 但“翻倍因子”继续在后台继承，影响下下局及以后
- 当出现非流局/非造反结局时：
  - 流局倍数恢复 ×1
  - 继承倍数恢复 ×1
