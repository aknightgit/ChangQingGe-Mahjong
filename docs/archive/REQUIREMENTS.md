# 一、项目概览

## 1.1 功能介绍

长清阁麻将是一款基于 Web 的四人在线麻将游戏，采用"上海麻将清混碰+四川血战到底"（ChangQingGe）变体规则。核心特色包括：

- **血战到底**：胡牌玩家离场，牌局继续直到只剩一人或牌墙摸完
- **百搭系统**：每局随机指定一张百搭牌，花牌分组百搭
- **造反机制**：首轮五毒散可触发造反，直接结束并下局翻倍
- **包三/包四**：吃碰杠互包赔付体系
- **乐子封顶**：多个牌型胡牌上限同为10番
- **AI Bot 对战**：训练好的 AI 策略，支持人机混合对战
- **144 张牌**：万/筒/条 + 风/箭 + 花牌完整牌组

## 3.3 回合与出牌规则

1. **先摸后打**: 轮到自己必须先摸牌，再打出一张 — `gameManager.ts` 状态机 ✅
2. **一回合一张**: 每次摸牌后只能打出一张 — `mustDiscard` 标志 ✅
3. **吃牌限制**: 只能吃上家（局中动态变化）打出的牌 — `handleChow()` 检查 ✅
4. **一炮多响**: 允许多家同时胡同一张牌 — `handleMultiHu()` ✅
5. **手牌上限**: 任何时候玩家手牌（暗牌+露牌）不得超过14张 — `executeAction(DRAW)` 前校验 ✅
6. **每回合操作限制**: 同一回合内，玩家最多摸一张打一张，或吃/碰一张打一张，不得连续摸牌或连续吃碰 — `isActionPending` + 服务端校验 ✅
7. **冻结机制（抢牌窗口）**: 玩家出牌后，碰/杠/胡机会与下家摸牌**并行推进**，不是串行等待 — 见 3.3.1 ✅

### 3.3.1 冻结机制（抢牌窗口）

> 核心原则：**碰/杠/胡是抢的机会，不是必须等待的环节。**

上家出牌后，系统**同时**启动两个并行流程：

| 流程 | 说明 | 时长 |
|------|------|------|
| **Pending 窗口** | 其他玩家看到碰/杠/胡按钮高亮，可抢牌 | 1秒 |
| **冻结计时器** | 下家进入冻结状态，等待决策窗口 | 参数化（默认1秒） |

**谁先完成谁赢：**

| 情况 | 结果 |
|------|------|
| 有人点击碰/杠/胡 | 立即执行，**接管回合**，冻结作废 |
| 冻结时间到且无人抢牌 | 下家**自动摸牌**，Pending 作废 |

**关键行为：**
- **没有"过"按钮**：不响应 = 放弃，自动流转
- **Bot 行为一致**：冻结期间 Bot 自动碰/过，时间到自动摸牌
- **决策窗口可配置**：建房时设置 `freezeDurationMs`（默认 1000ms）

**与旧设计的区别：**
- ❌ 旧：出牌 → 等所有人响应完 → 进下家（串行阻塞）
- ✅ 新：出牌 → 同时推进抢牌窗口 + 下家冻结（并行竞争）

## 3.4 百搭规则

### 3.4.1 百搭确定
- 每局从144张牌中随机指定一张作为百搭（不从牌墙移除）
- 百搭可替代任意牌参与胡牌判定
- ✅ 已实现 — `tiles.ts` 随机选择

### 3.4.2 花牌百搭组
- 春夏秋冬四张为一组百搭（若百搭牌属春夏秋冬，四张全部为百搭）
- 梅兰竹菊四张为一组百搭（若百搭牌属梅兰竹菊，四张全部为百搭）
- 百搭花牌摸到后进入手牌（不放门口，不补花）
- 普通花牌摸到后仍放门口，等回合补花
- ✅ 已实现

### 3.4.3 百搭打出限制
- 百搭打出后不可被吃/碰/杠 — `gameManager.ts` 限制检查 ✅
- 百搭打出后一圈内仅允许自摸胡 — `gameManager.ts` 胡牌条件 ✅
- 百搭被打出时触发一圈冷冻
- 冷冻期间：所有玩家不能吃/碰/捉冲
- 冷冻持续一圈（四个玩家各出一张牌后解冻）
- ✅ 已实现 — `freezeRound` 机制

### 3.4.5 风一色/风碰特殊结算
- 若百搭牌为风牌或箭牌，且胡牌牌型为风一色 → 可算无百搭(×2翻倍)
- 若百搭牌为风牌或箭牌，且胡牌牌型为风碰 → 需验证去掉百搭后牌面仍满足全刻子 → 可算无百搭(×2翻倍)
- ✅ 已实现

## 3.5 花牌规则

- 摸到花牌 → 普通花牌放入副露区 → 从牌墙尾部补牌
- 补到花牌 → 继续补，直到补到非花牌
- 花牌不参与胡牌牌型判断
- **八花自摸**: 一局内独家摸齐全部8朵花且自摸 = 固定10点 ✅

## 3.10 互包规则（包三/包四）

| 关系 | 条件 | 赔付倍数 |
|------|------|---------|
| 包三 | 吃/碰/杠另一方 3口 | ×3 |

### 结算规则
- **互包双方互相放冲**: 统一按 2倍 结算
- **第三方放冲**: 放冲者按 1倍 赔付，互包输家向胜者赔付 1倍
- **自摸三口互包**: 互包输家赔 3倍，其他玩家 1倍
- **自摸四口互包**: 互包输家赔 5倍，其他玩家不赔付
- ✅ 已实现

## 3.11 点数结算

### 最终公式
```
最终点数 = 牌型点数 × 额外翻倍 × 全局倍数
```

### 额外翻倍
| 条件 | 倍数 |
|------|------|
| 无百搭 | ×2 |
| 门清 | ×2 |

### 全局倍数
```
全局倍数 = min(8, 骰子倍数 × 流局倍数 × 继承倍数)
```
- **骰子倍数**: 1+1或4+4 = ×4，其他对子 = ×2，其他 = ×1
- **流局倍数**: 上一局流局或造反则 ×2，否则 ×1
- **继承倍数**: 来自上一局全局倍数链路
- 全局倍数封顶 8

### 流局与翻倍继承
- 流局 → 下局全局倍数 ×2
- 造反 → 下局全局倍数 ×2
- 封顶后翻倍因子仍后台继承到下一局，例：本局掷骰子之后理论16倍，但受限只能8倍，剩下2倍继承给下一局
- 出现非流局/非造反结局时，流局倍数和继承倍数恢复 ×1
- ✅ 已实现 — `scoring.ts` / `calculateGlobalMultiplier()`

## 3.13 超时规定与 AI 介入

### 出牌倒计时
| 规则 | 状态 |
|------|------|
| 摸牌后 60秒 内未出牌 → 自动打出摸到的牌 | ✅ |
| 连续 2次 超时自动操作后 → 由 AI 接管该玩家 | ✅ |
| AI 接管后 → 服务器标记 `botModePlayers`，由 botService 自动出牌 | ✅ |
| 玩家回来 → 点击「我回来了」按钮恢复控制 | ✅ |

### 超时自动操作类型（按优先级）
1. 有摸到的牌但没出 → 自动打出摸到的牌
2. 有优先操作（吃/碰/杠/胡）→ 自动过（本来的流转逻辑也去掉了其他玩家必须点击“过”选择不碰牌这个可能导致卡顿的操作）
3. 轮到摸牌 → 自动摸

### AI 接管逻辑
- 客户端计时器：`app/pages/gameroom/[roomId].vue` — `startTurnTimer()`, `handleAutoAction()`
- 客户端 UI：`isAIControlled` 状态 → 显示「🤖 AI托管中」+「我回来了」按钮
- 服务器：`server/utils/gameManager.ts` — `botModePlayers` Set + `enableBotMode()` / `disableBotMode()`
- API：`server/api/game/bot-mode.post.ts` — 托管控制端点



# 四、特殊规则声明

## 4.1 门清

- 没有吃过牌、碰过牌、门口无明杠 = 门清
- 暗杠不破门清
- 门清胡牌享受 ×2 翻倍
- ✅ 已实现

## 4.2 无百搭

### 触发条件
- 手牌中没有百搭牌（百搭牌当做原牌时仍能胡牌，也算无百搭）
- 特殊规则：若百搭牌为风牌或箭牌，且胡牌牌型为风一色 → 可算无百搭
- 特殊规则：若百搭牌为风牌或箭牌，且胡牌牌型为风碰 → 需验证去掉百搭后牌面仍满足全刻子 → 可算无百搭

### 结算
- 胡牌点数 ×2 翻倍
- ✅ 已实现

# 五、特色玩法

## 5.1 造反（五毒散）

### 触发条件
开局后首轮摸满手牌，轮到自己回合时手牌同时满足：
- 筒子、万子、条子三门都有（每门≥1张）
- 有风牌（东南西北任意）
- 有箭牌（中发白任意）
- 无花牌、无百搭
- 无对子或刻子（全是搭子/散牌）

### 效果
- 显示"我要造反/不造反"选项
- 选择造反 → 本局直接结束
- 下局全局倍数 ×2
- 造反者成为庄家
- ✅ 已实现 — `handleRebel()` + UI 心跳动画

## 5.2 梁山聚义

### 触发条件
- 4人全真人局（无AI玩家）
- 前3个回合内可发起投票

### 投票规则
- 每位活跃玩家可点击一次"梁山聚义"按钮
- 累积有效赢分超过被聚义QJ线的玩家 → 自动视为同意，无否决权
- 全员投票通过 → 本局结束，下把翻倍

### 被聚义QJ线
- 默认值 4000（可在建房时调整 0-99999）
- 有效输赢 = 累积赢分 × 结算膨胀倍数
- 突破QJ线的玩家：战绩榜显示 🤑 标识（赢超QJ线×3时触发红色呼吸灯）
- 每把开局时重新播报QJ线突破提醒

## 5.3 谢谢带头大哥

### 触发条件
- 某玩家首次打出某张牌（在本局中该牌从未被任何人打出过）

### 效果
- 该玩家赔付其余三家每家 10 分
- 从胡牌结算前扣除

## 5.4 我要换座（输家换位置）

### 触发条件
- 有效输分达到 QJ 线（默认输 4000 以上）

### 机会次数
- 输 4000 → 1 次机会
- 输 8000 → 2 次机会
- 输 12000 → 3 次机会（最多 10 次）

### 操作流程
- 满足条件时，点击其他真人玩家头像弹出「跟他换位置」选项
- 点击后锁定，下一局开始前生效
- 生效时机：随机选座位之前
- 庄家/骰子跟随赢家，不受换位影响

### 消息广播
- 满足条件时：「xxx玩家满足换位置条件啦」
- 选定换位时：「xxx玩家下一局开始与xxx互换位置」
