### 2.5 牌面方向（各位置玩家视角）

> 核心原则：每个玩家看到的牌面正方向 = 该玩家面对牌桌时"正面朝自己"的方向。

- 2.5.1 **本家（下/south）**：所有牌面正方向朝下（即牌头朝上，正面朝自己）→ `rotate(0deg)`
- 2.5.2 **上家（top/north）**：所有牌面正方向朝上（倒过来）→ `rotate(180deg)`
- 2.5.3 **左家（left/west）**：所有牌面正方向朝右 → `rotate(90deg)`
- 2.5.4 **右家（right/east）**：所有牌面正方向朝左 → `rotate(270deg)`

**适用范围（所有渲染单元统一方向）：**
- 弃牌区：每张弃牌按 2.5.1~2.5.4 方向旋转
- 手牌区（其他玩家）：牌背朝该玩家方向（与 2.5.1~2.5.4 一致）
- 露牌区：牌面朝上，头部朝向同该玩家方向
- 牌墙：牌背朝各自玩家方向（四边各不相同）

**旋转 CSS 示例：**
```css
/* 上家弃牌/手牌/露牌 */
.seat-top { transform: rotate(180deg); }
/* 左家 */
.seat-left { /* 内部元素 rotate(90deg) */ }
/* 右家 */
.seat-right { /* 内部元素 rotate(270deg) */ }
/* 本家 */
.seat-bottom { transform: rotate(0deg); }
```

### 2.6 牌头方向

> "牌头"= 麻将牌的上边缘（数字/图案的正上方）。牌头朝向 = 该玩家面对牌桌时头顶方向。

- 2.6.1 **本家**：牌头朝上（朝牌桌中心）→ 正常方向
- 2.6.2 **上家**：牌头朝下（朝牌桌中心）→ 旋转 180°
- 2.6.3 **左家**：牌头朝右（朝牌桌中心）→ 旋转 90°
- 2.6.4 **右家**：牌头朝左（朝牌桌中心）→ 旋转 270°

**规律：所有玩家的牌头都朝向牌桌中心。**

### 4.3 牌墙完整规格（双层 2.5D 效果）

#### 4.3.1 四边布局
- 上边（top）：18 张水平排列，从左到右，位于桌面顶部 11% 处
- 下边（bottom）：18 张水平排列，从右到左，位于桌面底部 11% 处
- 左边（left）：18 张垂直排列，从下到上，位于桌面左侧 11% 处
- 右边（right）：18 张垂直排列，从上到下，位于桌面右侧 11% 处
- 每边总牌数：18 张 × 2 层 = 36 张（实际物理 34 张/边，取 18 溢出容忍）
- 牌墙总计：4 × 18 = 72 slot 位置（按 remaining 动态隐藏）

#### 4.3.2 双层结构
- **内层（inner layer）**：`z-index: 1`，紧贴定位线
- **外层（outer layer）**：`z-index: 2`，向外偏移 `LAYER_OFFSET = 5px`，露出白色侧面
- 上边外层：向上偏移（`top: calc(11% - 5px)`），底部露出白色侧面
- 下边外层：向下偏移（`bottom: calc(11% - 5px)`），顶部露出白色侧面
- 左边外层：向左偏移（`left: calc(11% - 5px)`），右侧露出白色侧面
- 右边外层：向右偏移（`right: calc(11% - 5px)`），左侧露出白色侧面

#### 4.3.3 白色侧面 CSS
- 侧面高度/宽度：4px
- 颜色：`linear-gradient(#f0ead8 → #d0c8b8)`（象牙白→灰白渐变）
- 圆角：2px（朝向牌面方向一侧）
- 阴影：`box-shadow: 0 1px 2px rgba(0,0,0,0.2)`
- 方向：
  - 上边外层：底部侧面 `.tile-side-bottom { bottom: -4px; height: 4px; }`
  - 下边外层：顶部侧面 `.tile-side-top { top: -4px; height: 4px; }`
  - 左边外层：右侧侧面 `.tile-side-right { right: -4px; width: 4px; }`
  - 右边外层：左侧侧面 `.tile-side-left { left: -4px; width: 4px; }`

#### 4.3.4 牌背样式
- 内层牌背：
  - 渐变：`linear-gradient(155deg, #1a4a28 → #123a1e → #0a2212 → #040f08)`（深绿麻将色）
  - 高光：顶部 `rgba(255,255,255,0.15)` 线性渐变
  - 边框：`0.5px solid rgba(180,220,160,0.08)`
- 外层牌背：
  - 渐变：`linear-gradient(155deg, #2a6435 → #1a4a28 → #0e2c18 → #05120a)`（稍亮，立体感更强）
  - 高光：更强 `rgba(255,255,255,0.18)`
  - 阴影：`drop-shadow(0 1px 2px rgba(0,0,0,0.6))`

#### 4.3.5 响应式降级
- `@media (max-width: 1300px)`：牌 slot 缩至 22×32px（水平）/ 32×22px（垂直）
- `@media (max-width: 900px)`：牌 slot 缩至 16×24px（水平）/ 24×16px（垂直）
- `pointer-events: none`（牌墙不可点击）

#### 4.3.6 z-index 层级
- 牌墙整体：`z-index: 1`（`TileWall` 绝对定位覆盖整个 `.table-felt`）
- 座位区（手牌+露牌）：`z-index: 5`（在牌墙之上）
- 弃牌区：`z-index: 5`（同座位区）
- 中心信息区：`z-index: 4`（在牌墙之上，弃牌区之下）
