# 音效文件目录

将以下 MP3 文件放在此目录下：

| 文件名 | 用途 | 建议时长 |
|--------|------|----------|
| `tile-draw.mp3` | 摸牌 | 0.3-0.5s |
| `tile-discard.mp3` | 打牌（牌落到桌面） | 0.2-0.4s |
| `tile-chow.mp3` | 吃牌 | 0.3-0.5s |
| `tile-pong.mp3` | 碰牌 | 0.3-0.5s |
| `tile-kong.mp3` | 杠牌 | 0.4-0.6s |
| `tile-hu.mp3` | 胡牌（欢呼） | 1.0-2.0s |
| `tile-rebel.mp3` | 造反 | 0.5-1.0s |
| `dice-roll.mp3` | 掷骰子 | 1.0-1.5s |
| `timer-warn.mp3` | 倒计时警告（≤10s） | 0.2-0.3s |
| `turn-notify.mp3` | 轮到自己（提示音） | 0.3-0.5s |

## 免费音效来源

- [Freesound.org](https://freesound.org/) — 搜索 "mahjong", "tile", "dice"
- [Mixkit](https://mixkit.co/free-sound-effects/) — 游戏音效
- [Zapsplat](https://www.zapsplat.com/) — 棋牌类音效

## 注意

- 格式：MP3（兼容性最好）
- 音量：统一标准化到 -6dB ~ -3dB
- 如果文件不存在，音效系统会静默跳过，不影响游戏功能
