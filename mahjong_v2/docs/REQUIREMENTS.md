> 版本: v2.2 | 最后更新: 2026-03-28
>
> 本文档为长清阁麻将项目的唯一需求权威来源。代码实现以本文档为准。

## 一、牌具

### 1.1 牌的数量

| 类型 | 牌种 | 每种数量 | 小计 |
|------|------|----------|------|
| **万子** | 1-9万 | 4张 | 36张 |
| **筒子** | 1-9筒 | 4张 | 36张 |
| **条子** | 1-9条 | 4张 | 36张 |
| **风牌** | 东/南/西/北 | 4张 | 16张 |
| **箭牌** | 红中/发财/白板 | 4张 | 12张 |
| **花牌** | 梅/兰/竹/菊/春/夏/秋/冬 | 1张 | 8张 |

**总计: 136张 (不含花) / 144张 (含花)**

---

## 二、基础规则

- **牌数**: 144张
- **玩家**: 4人
- **庄家规则**: 两颗骰子，可重复掷（次数上限可配置，默认=2）
- **起牌数**: 庄家14张，其余人13张

---

## 三、通用动作

| 动作 | 触发条件 | 优先级 | 说明 |
|------|----------|--------|------|
| **摸牌** | 轮到自己回合 | 1 | 从牌墙摸一张牌 |
| **打牌** | 摸牌后 | 2 | 打出一张牌到牌池 |
| **吃牌** | 上家打牌 | 3 | 组成顺子 (如1-2-3万) |
| **碰牌** | 任意家打牌 | 4 | 组成刻子 (如3个一万) |
| **明杠** | 任意家打出第4张 | 5 | 碰牌后补杠，或打牌来杠 |
| **暗杠** | 手里有4张相同牌 | 5 | 不让人看到的杠 |
| **胡牌-自摸** | 自己摸到胡牌 | 6 | 摸牌成胡 |
| **胡牌-捉冲** | 其他家打出胡牌 | 6 | 点炮/放炮 |
| **胡牌-抢杠** | 他人自摸补杠时 | 6 | 按赢家牌面点数×3结算 |

**优先级**: 胡(自摸/捉冲/抢杠) > 杠(明杠/暗杠) > 碰 > 吃

## 四、术语

| 术语 | 含义 |
|------|------|
| **牌墙** | 桌面上未摸的牌，四方围成一圈 |
| **牌墙头** | 顺时针方向第一张 |
| **牌墙尾** | 顺时针方向最后一张 |
| **牌池** | 玩家打出的牌集中区域 |
| **手牌** | 玩家手里的牌 |
| **门口牌（副露区）** | 已吃/碰/杠/杠花的牌组 |
| **搭子** | 差一张成顺子的两张牌 (如12万差3万) |
| **对子** | 两张相同的牌 |
| **刻子** | 三张相同的牌 |
| **顺子** | 三张连续的同门牌 |
| **面子** | 顺子或刻子的统称 |
| **雀头** | 胡牌所需的一对 (将) |
| **听牌** | 只差一张即可胡牌的状态 |
| **流局** | 牌摸完无人胡牌 |
| **百搭/赖子** | 可代替任意牌的万能牌 |
| **血战到底** | 胡牌玩家离场，牌局继续直到仅剩一人或牌墙摸完 |
| **回合倍数** | 每局根据骰子点数组合确定的倍数 |
| **全局倍数** | 由流局/造反带来的跨局倍数累积（有上限） |
| **一炮双响** | 一张牌让两家同时胡牌 |
| **一炮多响** | 一张牌让多家同时胡牌 |
| **明杠** | 场上有人打出第4张时补杠 |
| **暗杠** | 手里有4张相同牌，不公开 |
| **补杠** | 碰牌后摸到第4张再杠 |
| **杠花** | 花牌移入副露区，从牌墙尾补牌 |
| **门清** | 整局没有吃/碰/明杠的情况下胡牌（允许暗杠、杠花） |
| **杠开** | 杠花或杠牌后补牌，刚好自摸胡牌 |
| **无花自摸** | 门口牌和手牌均无花牌，且无风向刻/杠，自摸胡牌 |

## 五、座次

- **东家**: 庄家，先起牌
- **南家**: 庄家下家
- **西家**: 对家
- **北家**: 庄家上家

## 六、造反规则

### 触发条件

开局后首轮摸满14张牌（或闲家摸满13张），**轮到自己回合**且满足五毒散的玩家可选择造反：

> **五毒散** = 手牌同时满足以下全部条件：
> - 筒子、万子、条子**三门花色都有**（每门至少1张）
> - 有风牌（东南西北任意）
> - 有箭牌（中发白任意）
> - **无花牌**
> - **无百搭**
> - **无对子或刻子**（全是搭子/散牌）

### 显示效果

- 满足条件的玩家牌桌上显示 **"我要造反 / 不造反"** 选项
- **"我要造反"按钮高亮+心跳动画**，用于提示与刺激

### 结算效果

- 此局**直接结束**（不继续打牌）
- **下回合点数翻倍**（×2）
- **造反人成为庄家**

---

## 七、包三家 / 包四家规则

### 定义

| 关系 | 触发条件 | 赔付倍数 |
|------|----------|----------|
| **包三家** | 某方吃/碰/杠另一方**三口** | 输家赔付时 ×3 |
| **包四家** | 某方吃/碰/杠另一方**四口** | 输家赔付时 ×5 |

### 约束

- **吃牌只能吃上家**（不能吃对家或下家的牌）
- 碰牌和杠牌可以碰任意家

### 结算规则（互包关系）

#### 互相放炮
- 互包双方互相放冲 → **统一按 2 倍结算**（不区分三口/四口）

#### 第三方放冲
- 第三方放冲给胜者 → 放冲者按 **1 倍**赔付
- 互包关系中的输家 → 向胜者赔付 **1 倍**

#### 一方自摸
- **三口互包**：互包输家向胜者赔付 **3 倍**；其他玩家 **1 倍**
- **四口互包**：互包输家向胜者赔付 **5 倍**；其他玩家 **0 倍**

### 示例

#### 互包互相放冲
- 甲乙包三口，乙放炮给甲 → 甲从乙收 **2 倍**
- 甲乙包四口，甲放炮给乙 → 乙从甲收 **2 倍**

#### 第三方放冲
- 甲乙包三口，丙放冲甲 → 丙赔甲 **1 倍**；乙赔甲 **1 倍**
- 甲乙包四口，丁放冲甲 → 丁赔甲 **1 倍**；乙赔甲 **1 倍**

#### 自摸
- 甲乙包三口，甲自摸 → 乙赔甲 **3 倍**；丙丁各赔 **1 倍**
- 甲乙包四口，甲自摸 → 乙赔甲 **5 倍**；丙丁 **不赔付**

## 八、胡牌牌型定义

### 牌型说明

| 牌型 | 手牌要求 | 门口牌要求 | 允许花牌/百搭 |
|------|----------|------------|---------------|
| **对对胡（即碰碰胡）** | 只有刻子、对子、杠牌 | 只有刻子、对子、杠牌 | ✅ 允许 |
| **清一色** | 只有筒子、万子、条子的**其中一门** | 只有筒子、万子、条子的**其中一门** | ✅ 允许 |
| **混一色** | 只有一门数牌 + 风牌 | 只有一门数牌 + 风牌（对子或刻子） | ✅ 允许 |
| **清碰** | 清一色 + 对对胡 | 清一色 + 对对胡 | ✅ 允许 |
| **风一色** | 全部是风牌（东南西北） | 全部是风牌 | ✅ 允许 |
| **风碰** | 全部是风牌 | 全部是风牌的**对子或刻子** | ✅ 允许 |
| **八花自摸** | 手牌+副露区共有**8朵花** | - | ✅ 纯花牌 |
| **四百搭** | 手牌有**4张百搭** | - | ✅ 纯百搭 |

> **注意**：所有牌型都**允许**手牌有花牌或百搭

### 牌型优先级

胡牌时从高到低判断：
1. 风碰 → 2. 风一色 → 3. 清碰 → 4. 八花自摸 → 5. 清一色 → 6. 混一色 → 7. 对对胡（碰碰胡）→ 8. 四百搭

---

## 九、门清判定

### 定义

满足**听牌条件**时：

- 没有吃过牌
- 没有碰过牌
- **门口无牌**（即没有吃/碰/明杠的牌组）

> 可以有暗杠和杠花

---

## 十、回合与出牌规则

- **先摸后打**：轮到自己回合必须先摸牌，再打出一张
- **一回合一张**：每次摸牌后只能打出一张牌
- **吃牌限制**：只允许吃上家打出的牌
- **一炮多响**：允许多家同时胡同一张牌，回合从**首个胡牌玩家右手**继续摸牌

---

## 十一、百搭规则

- **百搭确定**：发牌后从 144 张中随机选一张作为百搭（不移除牌墙）
- **用途**：可替代任意牌参与胡牌判定
- **出牌限制**：百搭被打出时，该回合**不可吃/碰/杠**
- **胡牌限制**：百搭被打出时，仅允许**自摸胡**，不可捉冲
- **捉冲限制**：若牌型为**碰碰胡**或**混一色**，且门口无花牌，则不可捉冲（仅可自摸）

---

## 十二、杠与补牌规则

- **暗杠**：手牌出现 4 张相同牌可暗杠，暗杠不露牌面
- **补杠（打牌补杠）**：手牌有三张相同牌，别人打出第 4 张可杠
- **补杠（自摸补杠）**：自己摸到第 4 张，无论刻子在手牌或门口都可补杠
  - **门口刻子补杠**：可触发抢杠
  - **手牌刻子补杠**：视为暗杠，不可抢杠
- **杠花**：花牌移入副露区（门口牌），从牌墙尾补牌
- **杠后补牌**：若补到花牌，继续补牌直到非花
- **门清**：暗杠不破门清
- **杠开**：杠牌/杠花补牌后胡牌，均视为**自摸杠开**（固定点数 10）

### 抢杠

- 仅在**自摸补杠**场景触发（门口刻子 + 自摸第4张）
- 手里三张自摸补杠属于暗杠，不可抢杠
- 其他玩家若满足胡牌条件，可抢杠胡
- 若抢杠牌型是**碰碰胡/混一色**，则门前（门口）必须有花牌才可抢杠
- 抢杠结算：按赢家牌型点数结算后，再 ×3，仅杠家向赢家赔付，其他玩家不参与
- 抢杠胡后，赢家右手玩家继续摸牌

---

## 十三、无花自摸

### 触发条件

- 牌型为**碰碰胡**或**混一色**
- **自摸胡牌**（非放冲）
- 门口**没有花牌**
- 手牌**没有风向刻子或风向杠**

### 结算

- 固定点数 **10点**

---

## 十四、点数结算规则

### 固定点数牌型（直接使用固定值）

| 牌型 | 点数 |
|------|------|
| 清一色 | 10点 |
| 风一色 | 20点 |
| 风碰 | 40点 |
| 清碰 | 20点 |
| 无花自摸 | 10点 |
| 杠开（杠花/杠牌后补牌自摸，含明杠） | 10点 |
| 八花自摸（手牌+副露共8朵花） | 10点 |
| 四百搭（手牌有4张百搭） | 10点 |

### 公式计算牌型（仅适用于：碰碰胡/混一色）

```
基础点数 = 2 + 花牌数 + 组合牌点数
```

> **公式点数上限：10点**

**组合牌点数**：
- 风牌刻子 = 1点
- 箭牌刻子 = 2点
- 风牌杠 = 2点
- 箭牌杠 = 3点
- 其他牌杠 = 1点
- 暗杠在上述基础上 **再+1点**

### 额外翻倍（可叠加）

| 条件 | 翻倍 |
|------|------|
| 无百搭（胡牌牌面不含百搭） | ×2 |
| 门清 | ×2 |

### 最终点数计算

```
最终点数 = 牌型点数 × 回合倍数 × 额外翻倍
```

- **回合倍数**: 骰子点数决定（1+4=×2；1+1=×4；4+4=×4；其他对子=×2；其他组合=×1）
- **全局倍数**: 由流局/造反叠加（详见流局与翻倍）
- **最终倍数**: 回合倍数 × 全局倍数（上限 8）
- **额外翻倍**: 无百搭×2，门清×2，可叠加

---

## 十五、流局与翻倍

### 流局翻倍

- 本局流局 → 下一局点数系数 **×2**

### 造反翻倍

- 触发造反 → 下一局点数系数 **×2**

### 叠加规则

- 造反和流局可叠加翻倍
- **最高系数 = 8**
- 每局开始时：最终倍数 = 骰子回合倍数 × 全局倍数

---

## 十六、战斗模式

**血战到底**：

- 牌局持续到**仅剩一名玩家**或**牌墙摸完**才结束
- 已胡牌玩家**离场**，不再参与后续回合
