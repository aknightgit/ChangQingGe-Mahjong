## 1. 牌具与基础规则 ✅

- [x] 144张牌创建（万筒条+风箭+花） — `initWall()`
- [x] 4人对局 — `Player` × 4
- [x] 骰子系统（可重复掷，默认2次） — `rollDice()`, `maxDiceRolls`
- [x] 庄家14张 / 闲家13张发牌 — `deal()`
- [x] 花牌自动补牌 — `dealOneTile()`, `drawTile()`

## 2. 通用动作 ✅

- [x] 摸牌 — `drawTile()` 含花牌循环补牌
- [x] 打牌 — `playTile()` 含响应窗口
- [x] 吃牌 — `canChow()` / `doChow()` / `getChowCombos()`（仅上家，多组合选择）
- [x] 碰牌 — `canPong()` / `doPong()`
- [x] 明杠 — `canKong()` / `doKong(isHidden: false)`
- [x] 暗杠 — `canHiddenKong()` / `doKong(isHidden: true)`
- [x] 自摸胡 — `canHu()` + `playerWins()`
- [x] 捉冲胡 — `canHu()` with pendingTile
- [x] 抢杠胡 — `_tryRobKong()` / `playerRobKongHu()` / ×3结算
- [x] 优先级: 胡 > 杠 > 碰 > 吃 — `processTurn()` 响应窗口机制

## 3. 造反规则 ✅

- [x] 五毒散检测 — `Player.isWuDuSan` getter
- [x] 触发条件（首轮、轮到自己、未决定） — `canRebel()`
- [x] 造反/不造反选择 — `decideRebel()`
- [x] 直接结束 + 下局翻倍 + 换庄 — `resolveRebelAsDraw()`
- [ ] UI：心跳动画提示（"我要造反"按钮高亮） — 未实现

## 4. 包三家/包四家 ✅

- [x] 吃/碰/杠来源记录 — `baoRelations` Map
- [x] 包关系计数 — `recordBao()`（双向记录）
- [x] 三口×3 / 四口×5判定 — `getBaoMultiplier()`
- [x] 互相放冲 ×2 — `_settleWin()` 互包互相放冲分支
- [x] 第三方放冲 ×1 — `_settleWin()` 第三方放冲分支
- [x] 自摸：三口×3，四口×5 — `_settleWin()` 自摸分支

## 5. 胡牌牌型 ✅

| 牌型 | 状态 | 对应函数 |
|------|------|----------|

| 清一色 | ✅ | `_isQingYiSe()` / `_isQingYiSeWithExtra()` |
| 混一色 | ✅ | `_isHunYiSe()` / `_isHunYiSeWithExtra()` |

| 八花自摸 | ✅ | `_isBaHuaZiMo()` |

- [x] 胡牌检测支持百搭万能牌 — `checkHu()` 含 wildCount 递归

## 6. 门清判定 ✅

- [x] 无吃/碰/明杠 = 门清 — `_calcExtraMultiplier()` 检查 meldHidden
- [x] 暗杠不破门清 — 暗杠 meldHidden=true
- [x] 门清翻倍 ×2 — `_calcExtraMultiplier()`

## 7. 百搭规则 ✅

- [x] 发牌后随机选百搭（不移除牌墙） — `generateWildTile()` / `deal()` 中随机
- [x] 百搭替代任意牌参与胡牌 — `checkHu()` wildCount
- [x] 百搭打出时不可吃/碰/杠 — `canChow/canPong/canKong` 中 `_isWildTile` 检查
- [x] 百搭打出时仅允许自摸 — `canHu()` 中 pendingTile isWild 检查
- [x] 碰碰胡/混一色+门口无花 → 不可捉冲 — `canHu()` 末尾条件

## 8. 杠与补牌规则 ✅

- [x] 暗杠（不公开） — `doKong(isHidden: true)`, `meldHidden=true`
- [x] 打牌补杠（别人打出第4张） — `doKong()` 明杠分支
- [x] 自摸补杠（门口刻子+自摸第4张） — `_tryRobKong()` 入口
- [x] 手牌刻子补杠 = 暗杠 — `_tryRobKong()` 判断
- [x] 杠花补牌 — `drawTile(isKongDraw: true)`
- [x] 补到花继续补 — `aiPlay()` / `playerDeclineRobKong()` 中 while 循环
- [x] 抢杠（仅门口刻子自摸补杠触发） — `_tryRobKong()`
- [x] 抢杠 ×3 结算 — `_robKongHu()` 中 `robTotal = total * 3`
- [x] 抢杠胡后赢家右手继续摸牌 — `_robKongHu()` 末尾

## 9. 无花自摸 ✅

- [x] 碰碰胡/混一色 + 自摸 + 无花 + 无风向刻/杠 — `_isWuHuaZiMo()`
- [x] 固定10点 — `_calcFixedScore()` 返回10

## 10. 点数结算 ✅

### 固定点数
| 牌型 | 点数 | 状态 |
|------|------|------|
| 清一色 | 10点 | ✅ |
| 风一色 | 20点 | ✅ |
| 风碰 | 40点 | ✅ |
| 清碰 | 20点 | ✅ |
| 无花自摸 | 10点 | ✅ |
| 杠开 | 10点 | ✅ (`_isGangKai`) |
| 八花自摸 | 10点 | ✅ |
| 四百搭 | 10点 | ✅ |

### 公式计算
- [x] `基础点数 = 2 + 花牌数 + 组合牌点数` — `_calcBasePoints()`
- [x] 上限10点 — `min(10, ...)`
- [x] 组合牌点数（风刻1/箭刻2/风杠2/箭杠3/其他杠1/暗杠+1） — `_calcMeldPoints()`
- [x] 无百搭 ×2 / 门清 ×2 — `_calcExtraMultiplier()`
- [x] 回合倍数（骰子决定） — `rollDice()` 中 roundMultiplier
- [x] 全局倍数（流局/造反叠加，上限8） — `globalMultiplier`, `finalMultiplier`

## 11. 流局与翻倍 ✅

- [x] 流局翻倍 ×2 — `resolveDraw()`
- [x] 造反翻倍 ×2 — `resolveRebelAsDraw()`
- [x] 可叠加，最高8 — `globalMultiplier.clamp(1, 8)`
