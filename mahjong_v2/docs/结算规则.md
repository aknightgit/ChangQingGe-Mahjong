# 长清阁麻将 - 点数结算规则

## 一、固定点数牌型（优先级最高，直接使用固定值）

| 牌型 | 点数 |
|------|------|
| 清一色 | 10点 |
| 风一色 | 20点 |
| 风碰 | 40点 |
| 无花自摸 | 10点（仅限 **碰碰胡/混一色** 且自摸） |
| 杠开（杠花/杠牌后补牌自摸，含明杠） | 10点 |
| 八花自摸（手牌+副露共8朵花） | 10点 |
| 四百搭（手牌有4张百搭） | 10点 |

---

## 二、公式计算牌型

```
基础点数 = 2 + 花牌数 + 组合牌点数
```

### 组合牌点数
| 类型 | 点数 |
|------|------|
| 风牌刻子 | 1点 |
| 箭牌刻子 | 2点 |
| 风牌杠 | 2点 |
| 箭牌杠 | 3点 |
| 其他牌杠 | 1点 |
| 暗杠 | 在上述基础上 +1点 |

---

## 三、额外翻倍（可叠加）

| 条件 | 倍数 |
|------|------|
| 无百搭（胡牌牌面不含百搭） | ×2 |
| 门清 | ×2 |

**最终点数 = 基础点数 × 翻倍系数**

---

## 四、包三家 / 包四家规则

### 定义

| 关系 | 触发条件 | 赔付倍数 |
|------|----------|----------|
| **包三家** | 某方吃了或碰了另一方**三口** | 输家赔付时 ×3 |
| **包四家** | 某方吃了或碰了另一方**四口** | 输家赔付时 ×5 |

### 约束
- 吃牌只能吃上家（不能吃对家或下家的牌）
- 碰牌和杠牌可以碰任意家

### 结算规则

#### 自摸时
- 甲乙包三家/四家，丙自摸 → 甲/乙正常付×1（无倍数）
- 甲丙包四家，丙自摸 → 甲付×5，乙丁不付

#### 放冲时
- 放冲者正常赔付
- 互包关系中的其他输家，赔付 = 放冲者输掉的点数

#### 互包玩家互相放冲
- 甲乙有三四口关系，互相捉冲 → **2倍关系**

---

## 五、特殊规则

### 血战到底
- 一家胡牌后继续，另外三家继续战斗
- 三家全部胡牌或牌墙摸完 → 结算

### 造反
- 首轮轮到自己回合且满足条件可选择造反/不造反
- 选择造反 → 本局直接结束，**下局倍数 ×2**，造反者成为庄家

### 流局翻倍
- 流局 → 下局倍数 ×2
- 最高封顶 ×8

### 抢杠结算
- 仅在“门口刻子 + 自摸第4张”补杠时可被抢杠
- 手里三张自摸补杠视为暗杠，不可抢杠
- 抢杠胡按赢家牌型点数计算后再 ×3
- 仅杠家向赢家赔付，其他玩家不参与
- 抢杠后由赢家右手玩家继续摸牌
