## 一、牌具

### 1.1 牌的数量

| 类型 | 牌种 | 每种数量 | 小计 |
|------|------|----------|------|
| **万子** | 1-9万 | 4张 | 36张 |
| **筒子** | 1-9筒 | 4张 | 36张 |
| **条子** | 1-9条 | 4张 | 36张 |
| **风牌** | 东/南/西/北 | 4张 | 16张 |
| **箭牌** | 红中/发财/白板 | 4张 | 12张 |
| **花牌** | 梅/兰/竹/菊/春/夏/秋/冬 | 1张 | 8张 |

**总计: 136张 (不含花) / 144张 (含花)**

## 二、通用动作

| 动作 | 触发条件 | 优先级 | 说明 |
|------|----------|--------|------|
| **摸牌** | 轮到自己回合 | 1 | 从牌墙摸一张牌 |
| **打牌** | 摸牌后 | 2 | 打出一张牌到牌池 |
| **吃牌** | 上家打牌 | 3 | 组成顺子 (如1-2-3万) |
| **碰牌** | 任意家打牌 | 4 | 组成刻子 (如3个一万) |
| **明杠** | 任意家打出第4张 | 5 | 碰牌后补杠，或打牌来杠 |
| **暗杠** | 手里有4张相同牌 | 5 | 不让人看到的杠 |
| **胡牌-自摸** | 自己摸到胡牌 | 6 | 摸牌成胡 |
| **胡牌-捉冲** | 其他家打出胡牌 | 6 | 点炮/放炮 |
| **胡牌-抢杠** | 其他家门口牌刻子摸到第四张杠牌，被他人抢杠胡 | 6 | 按赢家牌面3倍计算 |

**优先级**: 胡(自摸/捉冲) > 杠(明杠/暗杠) > 碰 > 吃

## 三、术语

| 术语 | 含义 |
|------|------|
| **牌墙** | 桌面上未摸的牌，四方围成一圈 |
| **牌墙头** | 桌面上未摸的牌，顺时针方向第一张为牌墙头 |
| **牌墙尾** | 桌面上未摸的牌，顺时针方向最后一张为牌墙尾 |
| **牌池** | 玩家打出的牌集中区域 |
| **手牌** | 玩家手里的牌 |
| **门口牌** | 玩家已经吃或碰组成的刻子/顺子/杠，以及已经杠花的花牌 |
| **搭子** | 差一张成顺子的两张牌 (如12万差3万) |
| **对子** | 两张相同的牌 |
| **刻子** | 三张相同的牌 (如3个一万) |
| **顺子** | 三张连续的同门牌 (如1-2-3万) |
| **面子** | 顺子或刻子的统称 |
| **雀头** | 胡牌所需的一对 (将) |
| **听牌** | 只差一张即可胡牌的状态 |
| **流局** | 牌摸完无人胡牌 |
| **百搭/赖子** | 可代替任意牌的万能牌 (有些玩法有) |
| **血战到底** | 胡牌玩家离场，牌局继续直到仅剩一人或牌墙摸完 | 
| **回合倍数** | 每局根据骰子点数组合确定的倍数 | 
| **全局倍数** | 由流局/造反带来的跨局倍数累积（有上限） |
| **一炮双响** | 一张牌让两家同时胡牌 |
| **一炮多响** | 一张牌让多家同时胡牌 |
| **明杠** | 场上有人打出第4张时补杠 |
| **暗杠** | 手里有4张暗杠，不公开 |
| **补杠** | 碰牌后摸到第4张再杠 |
| **杠花** | 手牌拿到花牌，从牌墙尾部补牌，花牌放到门口牌 |
| **门清** | 整局没有吃/碰/明杠的情况下胡牌（允许暗杠、杠花） |
| **杠开** | 杠花或杠牌后补牌，刚好自摸胡牌 |
| **无花自摸** | 门口牌和手牌均无花牌，且无风向刻/杠，自摸胡牌 |

## 四、座次

- **东家**: 庄家，先起牌
- **南家**: 庄家下家
- **西家**: 对家
- **北家**: 庄家上家

## 五、胡牌牌型

> 以下牌型为长清阁麻将常用牌型，详细说明待补充

| 牌型 | 说明 |
|------|------|
| **碰碰胡（对对胡）** | 所有面子都是刻子(碰牌)，无顺子 |
| **清一色** | 全部是同一种花色(万或筒或条) |
| **混一色** | 一种花色(万/筒/条) + 风牌/箭牌 |
| **清碰** | 清一色 + 碰碰胡 |
| **风一色** | 全部是风牌(东南西北) |
| **风碰** | 碰碰胡 + 全部是风牌 |
