# 🀄 玩法规则

> 不同地区/类型的麻将玩法规则定义

---

## 长清阁麻将

> 详细规则定义

---

## 一、基础规则

- **牌数**: 144张
- **玩家**: 4人
- **庄家规则**: 两颗骰子，可重复掷（次数上限可配置，默认=2）
- **起牌数**: 庄家14张，其余人13张

---

## 二、造反规则

### 触发条件

开局后首轮摸满14张牌（或闲家摸满13张），**轮到自己回合**且满足五毒散的玩家可选择造反：

> **五毒散** = 手牌同时满足以下全部条件：
> - 筒子、万子、条子**三门花色都有**（每门至少1张）
> - 有风牌（东南西北任意）
> - 有箭牌（中发白任意）
> - **无花牌**
> - **无百搭**
> - **无对子或刻子**（全是搭子/散牌）

### 显示效果

- 满足条件的玩家牌桌上显示 **“我要造反 / 不造反”** 选项
- **我要造反按钮高亮+心跳动画**，用于提示与刺激

### 结算效果

- 此局**直接结束**（不继续打牌）
- **下回合点数翻倍**（×2）
- **造反人成为庄家**

---

## 三、包三家 / 包四家规则

### 定义

| 关系 | 触发条件 | 赔付倍数 |
|------|----------|----------|
| **包三家** | 某方吃/碰/杠另一方**三口** | 输家赔付时 ×3 |
| **包四家** | 某方吃/碰/杠另一方**四口** | 输家赔付时 ×5 |

### 约束

- **吃牌只能吃上家**（不能吃对家或下家的牌）
- 碰牌和杠牌可以碰任意家

### 结算规则（互包关系）

#### 互相放炮
- 互包双方互相放冲 → **统一按 2 倍结算**（不区分三口/四口）

#### 第三方放冲
- 第三方放冲给胜者 → 放冲者按 **1 倍**赔付
- 互包关系中的输家 → 向胜者赔付 **1 倍**

#### 一方自摸
- **三口互包**：互包输家向胜者赔付 **3 倍**；其他玩家 **1 倍**
- **四口互包**：互包输家向胜者赔付 **5 倍**；其他玩家 **0 倍**

### 示例

#### 互包互相放冲
- 甲乙包三口，乙放炮给甲 → 甲从乙收 **2 倍**
- 甲乙包四口，甲放炮给乙 → 乙从甲收 **2 倍**

#### 第三方放冲
- 甲乙包三口，丙放冲甲 → 丙赔甲 **1 倍**；乙赔甲 **1 倍**
- 甲乙包四口，丁放冲甲 → 丁赔甲 **1 倍**；乙赔甲 **1 倍**

#### 自摸
- 甲乙包三口，甲自摸 → 乙赔甲 **3 倍**；丙丁各赔 **1 倍**
- 甲乙包四口，甲自摸 → 乙赔甲 **5 倍**；丙丁 **不赔付**

---

## 四、胡牌牌型定义

### 牌型说明

| 牌型 | 手牌要求 | 门口牌要求 | 允许花牌/百搭 |
|------|----------|------------|---------------|
| **对对胡（即碰碰胡）** | 只有刻子、对子、杠牌 | 只有刻子、对子、杠牌 | ✅ 允许 |
| **清一色** | 只有筒子、万子、条子的**其中一门** | 只有筒子、万子、条子的**其中一门** | ✅ 允许 |
| **混一色** | 只有一门数牌 + 风牌 | 只有一门数牌 + 风牌（对子或刻子） | ✅ 允许 |
| **清碰** | 清一色 + 对对胡 | 清一色 + 对对胡 | ✅ 允许 |
| **风一色** | 全部是风牌（东南西北） | 全部是风牌 | ✅ 允许 |
| **风碰** | 全部是风牌 | 全部是风牌的**对子或刻子** | ✅ 允许 |
| **八花自摸** | 手牌+副露区共有**8朵花** | - | ✅ 纯花牌 |
| **四百搭** | 手牌有**4张百搭** | - | ✅ 纯百搭 |

> **注意**：所有牌型都**允许**手牌有花牌或百搭

### 牌型优先级

胡牌时从高到低判断：
1. 风碰 → 2. 风一色 → 3. 清碰 → 4. 八花自摸 → 5. 清一色 → 6. 混一色 → 7. 对对胡（碰碰胡）→ 8. 四百搭

---

## 五、门清判定

### 定义

满足**听牌条件**时：

- 没有吃过牌
- 没有碰过牌
- **门口无牌**（即没有吃/碰/明杠的牌组）

> 可以有暗杠和杠花

---

## 六、回合与出牌规则

- **先摸后打**：轮到自己回合必须先摸牌，再打出一张
- **一回合一张**：每次摸牌后只能打出一张牌
- **吃牌限制**：只允许吃上家打出的牌
- **一炮多响**：允许多家同时胡同一张牌，回合从**首个胡牌玩家右手**继续摸牌

---

## 七、百搭规则

- **百搭确定**：发牌后从 144 张中随机选一张作为百搭（不移除牌墙）
- **用途**：可替代任意牌参与胡牌判定
- **出牌限制**：百搭被打出时，该回合**不可吃/碰/杠**
- **胡牌限制**：百搭被打出时，仅允许**自摸胡**，不可捉冲
- **捉冲限制**：若牌型为**碰碰胡**或**混一色**，且门口无花牌，则不可捉冲（仅可自摸）

---

## 八、杠与补牌规则

- **暗杠**：手牌出现 4 张相同牌可暗杠，暗杠不露牌面
- **补杠（打牌补杠）**：手牌有三张相同牌，别人打出第 4 张可杠
- **补杠（自摸补杠）**：自己摸到第 4 张，无论刻子在手牌或门口都可补杠
  - **门口刻子补杠**：可触发抢杠
  - **手牌刻子补杠**：视为暗杠，不可抢杠
- **杠花**：花牌移入副露区（门口牌），从牌墙尾补牌
- **杠后补牌**：若补到花牌，继续补牌直到非花
- **门清**：暗杠不破门清
- **杠开**：杠牌/杠花补牌后胡牌，均视为**自摸杠开**（固定点数 10）

### 抢杠

- 仅在**自摸补杠**场景触发（门口刻子 + 自摸第4张）
- 手里三张自摸补杠属于暗杠，不可抢杠
- 其他玩家若满足胡牌条件，可抢杠胡
- 若抢杠牌型是**碰碰胡/混一色**，则门前（门口）必须有花牌才可抢杠
- 抢杠结算：按赢家牌型点数结算后，再 ×3，仅杠家向赢家赔付，其他玩家不参与
- 抢杠胡后，赢家右手玩家继续摸牌

---

## 九、无花自摸

### 触发条件

- 牌型为**碰碰胡**或**混一色**
- **自摸胡牌**（非放冲）
- 门口**没有花牌**
- 手牌**没有风向刻子或风向杠**

### 结算

- 固定点数 **10点**

---

## 十、点数结算规则

### 固定点数牌型（直接使用固定值）

| 牌型 | 点数 |
|------|------|
| 清一色 | 10点 |
| 风一色 | 20点 |
| 风碰 | 40点 |
| 清碰 | 20点 |
| 无花自摸 | 10点 |
| 杠开（杠花/杠牌后补牌自摸，含明杠） | 10点 |
| 八花自摸（手牌+副露共8朵花） | 10点 |
| 四百搭（手牌有4张百搭） | 10点 |

### 公式计算牌型（仅适用于：碰碰胡/混一色）

```
基础点数 = 2 + 花牌数 + 组合牌点数
```

> **公式点数上限：10点**

**组合牌点数**：
- 风牌刻子 = 1点
- 箭牌刻子 = 2点
- 风牌杠 = 2点
- 箭牌杠 = 3点
- 其他牌杠 = 1点
- 暗杠在上述基础上 **再+1点**

### 额外翻倍（可叠加）

| 条件 | 翻倍 |
|------|------|
| 无百搭（胡牌牌面不含百搭） | ×2 |
| 门清 | ×2 |

### 最终点数计算

```
最终点数 = 牌型点数 × 回合倍数 × 额外翻倍
```

- **回合倍数**: 骰子点数决定（1+4=×2；1+1=×4；4+4=×4；其他对子=×2；其他组合=×1）
- **全局倍数**: 由流局/造反叠加（详见流局与翻倍）
- **最终倍数**: 回合倍数 × 全局倍数（上限 8）
- **额外翻倍**: 无百搭×2，门清×2，可叠加

---

## 十一、流局与翻倍

### 流局翻倍

- 本局流局 → 下一局点数系数 **×2**

### 造反翻倍

- 触发造反 → 下一局点数系数 **×2**

### 叠加规则

- 造反和流局可叠加翻倍
- **最高系数 = 8**
- 每局开始时：最终倍数 = 骰子回合倍数 × 全局倍数

---

## 十二、战斗模式

**血战到底**：

- 牌局持续到**仅剩一名玩家**或**牌墙摸完**才结束
- 已胡牌玩家**离场**，不再参与后续回合

### 基础规则

- [ ] 牌数：144张
- [ ] 玩家：4人
- [ ] 庄家规则：庄家开局，有两次掷骰子的机会
- [ ] 起牌数：庄家14张，其余人13张

### 待定规则项目

| 类别 | 规则项 | 说明 |
|------|--------|------|
| **战斗模式** | 血战到底 | 有三个人胡牌，或者所有牌墙都被摸走，本局才结束。抢先胡牌的玩家暂时离场，不在场上。 |
| **胡牌牌型** | 仅包含：碰碰胡，清混碰，清一色，风一色，混一色，风碰 | 碰碰胡以及混一色，如若玩家门口牌没有花牌或者风向刻、风向杠，则无权捉冲 |
| **百搭用法** | 允许百搭 | 百搭可以充当任何牌使用，参与组成胡牌牌型。百搭由庄家掷骰子，取骰子最大的点数N，从牌墙尾倒数第2N张牌决定 |
| **骰子规则** | 有两个骰子；决定初始摸牌位置 | 庄家每局开始前掷骰子，有两次掷骰子机会 |
| **点数结算规则** | 胜者加点数，输家扣点数 | 赢家收取放冲玩家点数，自摸玩家收取场上剩余所有玩家点数。<br><br>**固定点数牌型（直接使用固定值，不参与公式计算）**：<br>- 清一色=10点<br>- 风一色=20点<br>- 风碰=40点<br>- 无花自摸=10点（门口牌和手牌均无花牌，且无风向刻/杠，自摸）<br>- 杠开=10点（杠花或杠牌后补牌刚好自摸）<br><br>**公式计算牌型**：<br>基础点数 = 2 + 花牌数 + 组合牌点数（**上限10点**）<br><br>**组合牌点数**：<br>- 风牌刻子=1点，箭牌刻子=2点<br>- 风牌杠=2点，箭牌杠=3点，其他牌杠=1点<br>- 暗杠在上述基础上再+1点<br><br>**额外翻倍（可叠加）**：<br>- 无百搭翻倍：手牌无百搭，×2<br>- 门清翻倍：门清做成胡牌，×2 |
| **包三家** | 三口包三家，四口包五家 | **触发条件**：某方单向吃/碰另一方三口或四口<br>- 甲吃/碰乙三口 → 乙→甲赔付时×3<br>- 甲吃/碰乙四口 → 乙→甲赔付时×5<br><br>**结算规则**：<br>- 只有自摸时 才×系数（放冲不×系数）<br>- 输赢关系是相互的（不管谁放冲）<br>- 举例：甲乙成立三口关系，丙放冲甲，则乙向甲赔付丙输掉的点数<br>- 如果甲乙之间放冲，则点数只翻倍×2，不再×3或×5 |
| **造反** | 首轮发牌结束，庄闲第一回合第一次拿满起手牌时 | 触发条件：14张牌(庄)或13张牌(闲)包含：筒子+条子+万子(三种花色都有) + 有风牌 + 有箭牌 + 没有花牌 + 没有百搭 + 手牌没有对子或刻子(全是搭子/散牌)。<br>效果：下一局点数翻倍(×2)，造反人变成庄家。所有玩家均可触发。 |
| **流局翻倍** | 流局则下局翻倍 | 本局流局，则下一局默认点数系数×2。<br>造反和流局可叠加翻倍，最高系数=8。 |
