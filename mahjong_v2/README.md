# 长清阁麻将 v2.0 (重构版)

## 目标
从零重构麻将游戏，实现：
1. 在线多人对战
2. 传统麻将风格 UI（匹配参考图）
3. 完整游戏流程
4. 完整规则实现

## 规则摘要
详见 `docs/玩法规则.md`

### 核心规则
- 144张牌，4人
- 造反（五毒散牌型）
- 血战到底
- 包三家/四家
- 点数结算

### UI 参考
- 背景：深蓝色
- 桌布：浅蓝灰渐变
- 牌墙：左右两侧，绿背
- 手牌：底部中央
- 弃牌：中央

## 技术栈
- Flutter
- MariaDB (数据存储)
